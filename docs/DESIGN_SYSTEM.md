# Design system (Phase 0)

## Palette

| Token | Hex | Use |
|---|---|---|
| canvas | `#F7F5F1` | Page background |
| surface | `#FFFFFF` | Cards / panels |
| ink | `#1A2B33` | Primary text |
| muted | `#5C6B73` | Secondary text |
| primary | `#1F6F78` | Links, focus, brand |
| primary-hover | `#185A61` | Hover |
| accent | `#D4A054` | Primary CTAs |
| accent-deep | `#C8873A` | CTA hover |
| success / warning / danger | `#2F8F6B` / `#C9873A` / `#C45C4A` | Status |
| line | `#E4E0D8` | Borders |
| mint | `#9FD8D3` | Soft highlight |

## Typography

- Display: **Syne** (headings, brand)
- Body / UI: **Outfit**

## Core components (scaffolded)

Button, Card, EmptyState, Skeleton, Navbar, MainLayout.

## Principles

Calm academic, distraction-free, mobile-first, generous whitespace, no ads/social noise. Optional dark mode later via CSS variables.
